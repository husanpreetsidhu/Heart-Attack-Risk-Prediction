# ❤️ Heart Attack Risk Prediction Using Machine Learning

## 📌 Project Overview

Heart Attack Risk Prediction is a Machine Learning project developed using Python and Scikit-learn. The project focuses on applying machine learning techniques to analyze health-related data and predict the possibility of heart attack risk.

The main purpose of this project is to explore how machine learning can support data-driven analysis in the healthcare domain.

## 🎯 Project Objectives

- Understand and analyze the dataset.
- Perform data preprocessing and prepare data for machine learning.
- Develop a machine learning-based prediction system.
- Evaluate the model's predictive performance.
- Understand the practical application of machine learning in healthcare analytics.

## ⚙️ Project Workflow

1. **Data Understanding:** Explore the dataset and understand the available variables.
2. **Data Preprocessing:** Prepare the data for machine learning.
3. **Model Development:** Apply machine learning techniques to build a prediction model.
4. **Model Evaluation:** Evaluate the predictive performance of the developed model.
5. **Prediction:** Use the trained model to generate predictions.

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/Husanpreet0/Heart-Attack-Risk-Prediction.git
```

2. Navigate to the project folder:

```bash
cd Heart-Attack-Risk-Prediction
```

3. Install the required libraries:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
```

4. Open Jupyter Notebook:

```bash
jupyter notebook
```

5. Open `heart_ml_project.ipynb` and execute the notebook cells.
